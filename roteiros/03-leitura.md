### 1 · Gancho

It's SA·tur·day. / It's past two in the morning. / And I'm watching one **more** E·pi·sode of a show I'm not even paying attention to anymore. //

I spent the whole day cleaning the house, / buying GRO·ce·ries, / cooking for the week. / And now that it's finally over, / I just... / **won't** let it end. / Even though I know **exactly** how I'm going to feel to·MOR·row. //

I've been doing this for as long as I can remember. / So today I want to FIG·ure out **why**. //

### 2 · Nomear o padrão

It turns out this has a name, / and it's an **actual** scien·TI·fic term. / In 2014 (twenty fourteen), / a group of re·SEAR·chers in the NE·ther·lands called it **bedtime pro·cras·ti·NA·tion**: / going to bed later than you planned, / when **nothing** is actually stopping you. //

So yes. // Pro·cras·ti·NA·tion. // The same thing we do with the work we don't want to start, / we do with sleep. //

And at some point, / people online added **one** word to it: / re·VENGE. / Because that's **exactly** what it feels like. / Like you're taking back a few hours / from a day that took everything from you. //

### 3 · Desnormalizar

For years, / my explanation was simple: / I'm just a night person. / I have no DIS·ci·pline. / I need to put the phone down. //

But here's the thing. / I started studying at night when I was twelve. / In college, / I'd get home after eleven / and do my a·SSIGN·ments in the middle of the night. / I'm thirty-five now. //

So I have to ask myself: / was I **born** a night owl? / Or was I **trained** to be one? // Maybe a bit of both. / Some people really are wired for late nights. / But I don't think my body chose this alone. / I think my **life** has been choosing it for me / for more than twenty years. //

### 4 · Por que acontece

When I look at my EVE·nings HON·est·ly, / I can see **four** things going on. //

One: / the night is the **only** time that feels like mine. //

I get home from work tired, / and before anything else, / I pick up my phone. / Just for a minute. / And that minute is the only part of the day / nobody is asking anything from me. / So of course I hold on to it. //

Two: / the day doesn't end when work ends. //

Because after the phone, / there's the shower. / And skincare. / And the dishes. / And the lunches for tomorrow. / And all the other little things / that somehow always end up at night. / And I have to find the COUR·age / to start **every single one** of them. //

There's a name for this too. / Back in 1989 (nineteen eighty-nine), / the so·ci·O·lo·gist Arlie HOCH·schild called it **the second shift**: / all the work that starts / when your actual work is over. / She was writing about working women, / and I think a lot of us will REC·og·nize ourselves in that. //

Three: / the way I rest is de·SIGNED to keep me awake. //

A book has a last page. / A feed **doesn't**. / And streaming starts the next episode / before I've even de·CI·ded if I want it. / On top of that, / the light from screens tells my brain it's still DAY·time. //

Four: / my brain doesn't want to switch off. //

And this is the strangest part. // I'm ex·HAUS·ted. / And I **still** fight to stay awake. / I keep doing things, / I keep scrolling, / like I'm AC·tive·ly resisting sleep. //

People have a name for this feeling: / tired but WIRED. / Your body is done, / but your mind is still running, / like the day hasn't let go of it yet. / From what I've read, / stress can keep the body in alert mode, / even at night, / when it should be slowing down. / And maybe that's why the phone feels so good at that hour. // It's **not** rest. / It just keeps my brain busy enough / that I don't have to feel how tired I am. //

### 5 · O custo real

And then I wake up already tired. / Not "I need a coffee" tired. / Tired the whole day. / I don't perform the way I want to at work. / I feel sleepy in the afternoon. / And every time I go to bed late, / there's the same feeling: / regret, / and the CER·tain·ty that tomorrow is already a little bit RU·ined. //

Most a·DULTS need at least seven hours of sleep. / On a lot of nights, / I'm not even close. //

There's another cost I don't talk about much. / I'm trying to lose some weight, / and I know bad sleep makes that harder. / There's research linking short sleep / to the HOR·mones that control hunger. / So the hours I steal at night, / I pay back during the day, / in more ways than **one**. //

### 6 · A virada

The last time I really slept well was on va·CA·tion. / We stayed near a park, / close to NA·ture. / I was with my family, / so my phone was mostly for·GOT·ten in a corner. / And my mom and my sister took care of the cooking. //

And I slept. // Easily. // Like I hadn't in years. //

At first I thought it was the nature. / The fresh air. / And that PROB·ab·ly helped. / But when I think about it now, / I think the biggest difference was something else. / For a few days, / somebody took the three hundred little tasks off my plate. / Nobody needed me to do the dishes or prepare the lunches. / The day ended // when it ended. //

So maybe my problem was **never** the night. / It was the **day**. / If the only free time I get / is the time I steal from sleep, / then sleep is always going to lose. //

### 7 · O que estou tentando

I'm not going to give you a perfect night rou·TINE. / I don't have one. //

What I have is a rule that **actually** worked for a while: / no screens and no bright lights after nine. / I light some CAN·dles, / take a shower, / and get ready for bed slowly. / When I did that, / it really helped. //

The hard part is keeping it. / Because the rule takes care of the night, / but it doesn't do anything about the day. // The dishes are **still** there. //

(Opcional, CBD) Some nights I also use CBD (si-bi-DI), / but that's my own choice, / not advice. / Please talk to a doctor before trying anything like that. //

### 8 · Fecho

So this week, / I'm not trying to be perfect. / I'm trying **two** things. //

The candle rule, / but only on WEEK·nights. / The WEEK·end can be the weekend. //

And one small piece of free time / that I take during the day / instead of stealing it at night. / Even twenty minutes. / Because I shouldn't have to wait until two in the morning / to feel like my time is **mine**. //

Tell me in the COM·ments: / what time did you actually fall asleep last night? / And what's on your second shift? //

And if you're watching this at one in the morning... // I **see** you. // Maybe close this one, / and finish it tomorrow. / I'll still be here.
